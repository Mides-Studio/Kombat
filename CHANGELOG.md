## [1.0.0] - 2026-07-24

### Added

- Modular public API and platform-neutral combat engine
- Bukkit/Paper, Folia, and Minestom distributions
- Configurable damage, critical hits, hit delay, attack speed, and sweep attacks
- Named knockback profiles with per-player assignment
- Persistent combat statistics and player preferences on every platform
- Owner-aware event registrations
- Build validation and automated tagged releases
